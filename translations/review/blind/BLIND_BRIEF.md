# Blind test — อ่านคำแปลไทยล้วนโดยไม่เห็นต้นฉบับ (Judgment ม็อดแปลไทย · 7 ก.ย. 2026)

## บทบาท
คุณเป็น **ผู้อ่านทดสอบชาวไทย** (ไม่ใช่นักแปล) ของม็อดแปลไทยเกม Judgment (RGG Studio · คามุโรโจ ปี 2018 · ตัวเอก
ทาคายูกิ ยากามิ อดีตทนายผันตัวเป็นนักสืบ) คุณจะได้อ่าน **เฉพาะฝั่งไทย** ของบทพูดตามลำดับฉาก เหมือนผู้เล่นที่นั่งอ่านซับในเกม
โดย **ไม่มีต้นฉบับอังกฤษให้เทียบ** — งานของคุณคือรายงานจุดที่ผู้เล่นไทยจะ "สะดุด" จริง ๆ ไม่ใช่จุดที่คุณอยากเขียนให้สวยกว่าเดิม

ทำไมต้องอ่านแบบไม่เห็นต้นฉบับ: รอบตรวจก่อนหน้าเทียบคู่ EN/TH แล้วผู้ตรวจ "เข้าใจไปเอง" เพราะเห็นอังกฤษอยู่ข้าง ๆ
แต่ผู้เล่นรายงานเข้ามาว่าหลายประโยค "อ่านแล้วแปลก" (รูปประโยคติดโครงอังกฤษ · คำลงท้ายซ้ำ · ช่องว่างผ่าวลี) — คุณต้องเป็นคนจับสิ่งนั้น

## ไฟล์ชิ้นงาน
`translations/review/blind/chunk_NN.tsv` — 4 คอลัมน์คั่นด้วย tab: `id` · `ฉาก` · `ผู้พูด` · `TH`
- `ฉาก` = บท/ชนิด + ชื่อฉากในไฟล์เกม (บรรทัดในฉากเดียวกันเรียงตามลำดับที่ปรากฏ อ่านต่อกันเป็นบทสนทนาได้)
- `ผู้พูด` = ชื่อผู้พูด (ภาษาอังกฤษตามไฟล์เกม) + เพศในวงเล็บ: (ช) ชาย · (ญ) หญิง · (กลาง) หลายคนใช้ร่วม · (?) ไม่ทราบ
  · ป้าย `[อีกแทร็ก]` = บรรทัดเดียวกันอีกเวอร์ชันสำหรับซับของอีกภาษาเสียง — อ่านแยกกัน **ไม่ต้องรายงานว่าสองแทร็กไม่เหมือนกัน**
- `TH` = คำแปลไทย · `\n` ที่เห็นเป็นตัวอักษร backslash+n คือการขึ้นบรรทัดใหม่ในเกม
- ข้อความในวงเล็บ ( ) มักเป็นความคิดในใจของยากามิ

## สิ่งที่ต้องรายงาน (หมวด)
| หมวด | ความหมาย | ตัวอย่างที่ผู้เล่นเคยรายงานจริง |
|---|---|---|
| **U** ไม่เข้าใจ/กำกวม | อ่านแล้วไม่รู้ว่าพูดถึงอะไร หรือตีความได้สองทางจนงง | — |
| **N** ไม่เป็นธรรมชาติ | เรียงคำแบบอังกฤษ · สำนวนแปลตรงตัว · คำที่คนไทยไม่ใช้ในบริบทนั้น · ประโยคยาวพันกัน | "ยินดีต้อนรับ...ก็ได้แหละ" |
| **T** พิมพ์ผิด/คำเพี้ยน | สะกดผิด · คำหาย/ตกหล่น · ชื่อเดียวกันสะกดสองแบบภายในชิ้น | "(สินี่คงเป็นฝาแฝดกันสินะ)" · "แล้ ว" · "หหรวน" |
| **P** สรรพนาม/คำลงท้ายผิดคน | ผู้พูดหญิงใช้ ผม/ครับ (หรือกลับกัน) · ตัวละครเดียวกันสลับระดับ (ผม↔ฉัน↔กู) กลางฉากโดยไม่มีเหตุ · จับคู่ข้ามระดับ เช่น "ผม…มึง" | หญิงในคัตซีนลงท้าย "ครับ" |
| **R** ซ้ำจนรก | คำลงท้าย (วะ/นะ/ครับ/เลย) หรือคำเดิมซ้ำถี่ผิดปกติในบรรทัดเดียว/สองบรรทัดติดกัน | "อย่ามายุ่งเรื่องกูวะ!\nมึงคิดว่าตัวเองเป็นใครวะ!?" |
| **S** ช่องว่างผ่าคำ | ช่องว่างตกกลางคำหรือกลางวลีที่ต้องอ่านติดกันจนความหมายเพี้ยน | "โจรขโมยกางเกงใน จอมกล้าไปที่ต้นตอ" (ควรเป็น "โจรขโมยกางเกงในจอมกล้า ไปที่ต้นตอ") |
| **F** ติดอ่าง/อุทานผิดรูป | ตัวหน้าขีดไม่ใช่ตัวเขียนตัวแรกของคำ · อุทานที่คนไทยไม่ใช้ | "แ-คุณ!" (ควรเป็น "ค-คุณ!") · "แหก!" แทน "โอ๊ย!" |

ระดับความรุนแรง `sev`:
- `high` = ผู้เล่นสะดุดแน่ ๆ / ความหมายหาย / ผิดเพศชัดเจน / คำผิด
- `mid` = อ่านได้แต่ขัด ๆ อยากให้คนแปลดูอีกที

## สิ่งที่ **ไม่ต้อง** รายงาน (จะถูกทิ้ง และทำให้รายงานของคุณน่าเชื่อถือน้อยลง)
- แก้สไตล์ตามรสนิยม / อยากเรียบเรียงใหม่ทั้งที่ของเดิมอ่านรู้เรื่องดี
- **ช่องว่างกลางประโยคที่อยู่ขอบคำ/ขอบวลี** — ตั้งใจแทรกทุก ๆ ~30 ตัวอักษรเพื่อให้เอนจิ้นตัดบรรทัดได้ (เอนจิ้นตัดได้เฉพาะที่ช่องว่าง)
  รายงานหมวด S เฉพาะเมื่อช่องว่างผ่า **กลางคำ** หรือแยกวลีที่ต้องอ่านติดกันจริง ๆ
- ชื่อคน/ร้าน/สถานที่ที่ทับศัพท์ดูแปลกตา — สะกดตามระบบของโปรเจกต์ (ยากามิ · ไคโตะ · ซุกิอุระ · โฮชิโนะ · ชินทานิ · ซาโอริ ·
  อาจารย์เก็นดะ · อายาเบะ · ฮามุระ · มาฟุยุ · ฮิงาชิ · คิโดะ · อิซุมิดะ · ฮัตโตริ · มัตสึกาเนะ · เคียวเรอิ · คุโรอิวะ · มุราเสะ · ชิโอยะ ·
  คุริโมโตะ · เอมิ · โอคุโบะ) — ถ้าสงสัยชื่อไหนให้ Grep คำอังกฤษใน `translations/glossary.md` (ห้ามอ่านทั้งไฟล์ ใหญ่ 158 KB)
  · รายงานเฉพาะ **สะกดไม่สม่ำเสมอภายในชิ้นเดียวกัน** (หมวด T)
- markup ของเอนจิ้น เช่น `<color=…>` `</color>` `<symbol=button_decide>` `${value}` `\n` — ไม่ใช่ข้อบกพร่อง
- ความหยาบ (กู/มึง/วะ) ในปากอันธพาล/ยากูซ่า — ปกติ · ยากามิเองแทนตัว "ผม" เสมอ ไม่ใช้ กู/มึง เด็ดขาด
- ผู้พูด (?) เพศไม่ทราบ → อย่ารายงานเรื่อง ครับ/ค่ะ เว้นแต่ป้ายผู้พูดเดียวกันสลับเพศไปมาในฉากเดียวกัน
- คำแทนตัว "ฉัน" ในความคิดในใจ ( ) ของยากามิ — ปกติ (คิดในใจใช้ ฉัน ได้ พูดออกเสียงใช้ ผม)
- ข้อความทดสอบของผู้พัฒนา เช่น "ข้อความทดสอบซูโกโรกุ" — ข้าม

## กติกาสรรพนามของโปรเจกต์ (ใช้ตัดสินหมวด P)
- ระดับสรรพนามมาเป็นคู่: **T1** ผม/ดิฉัน/ฉัน(หญิง) ↔ คุณ/นาย/ชื่อ + ครับ/ค่ะ · **T2** ฉัน ↔ แก (ไม่มีครับ/ค่ะ) · **T3** กู ↔ มึง
- ผสมข้ามระดับในความสัมพันธ์เดียวกัน ("ผม…มึง" · "กู…คุณ") = ผิด · สลับระดับได้เฉพาะเมื่ออารมณ์แตกกลางฉากอย่างชัดเจน
- ยากามิ = T1 เสมอ (ผม) · เรียกไคโตะ/เพื่อนสนิทว่า "นาย" ได้ · ผู้หญิงทางการ (อัยการ/ทนาย/หมอ) = ดิฉัน · ผู้หญิงสนิท/ห้าว = ฉัน

## วิธีอ่าน
1. อ่านไฟล์ชิ้นด้วย Read ทีละช่วง (offset/limit ช่วงละ ~250 บรรทัด) **จนครบทุกบรรทัด** — ห้ามอ่านครึ่งเดียวแล้วสรุป
2. อ่านเป็นบทสนทนาต่อเนื่องในฉากเดียวกัน — ประโยคที่ดูแปลกเดี่ยว ๆ แต่เข้ากับบรรทัดก่อน/หลัง ไม่ต้องรายงาน
3. จดเฉพาะจุดที่สะดุดจริง อัตราปกติของงานคุณภาพดีอยู่ราว 1-4 บรรทัดต่อ 100 บรรทัด — อย่ายัดให้ครบโควตา และอย่าปล่อยผ่านเพราะขี้เกียจจด

## เอาต์พุต
เขียนไฟล์ `translations/review/blind/findings_NN.json` (NN = เลขชิ้นของคุณ) เป็น JSON array — ต่อ 1 จุด:
```json
{"id": "B03-0123", "cat": "N", "sev": "high", "note": "เหตุผลสั้น ≤ 25 คำ ว่าสะดุดตรงไหน", "th_new": "…คำแก้ (ถ้าเสนอได้)…"}
```
- `th_new` ใส่เฉพาะเมื่อแก้ได้ชัด ๆ (ไม่บังคับ) และต้องทำตามนี้: จำนวน `\n` เท่าเดิม (เขียนเป็น backslash+n เหมือนในไฟล์ชิ้น) ·
  markup ทุกตัวครบและอยู่ลำดับเดิม · ช่วงอักษรไทยติดกันไม่มีช่องว่าง **ห้ามยาวเกิน 36 ตัว** (ยาวให้แทรกช่องว่างที่ขอบวลี) ·
  ยาวไม่เกิน ~1.3 เท่าของเดิม · ห้ามเปลี่ยนระดับสรรพนามนอกจากเป็นหมวด P · แก้เท่าที่จำเป็น
- ถ้าไม่พบเลย เขียน `[]`
- เกิน ~150 จุดให้แตกเป็น `findings_NN.part1.json`, `findings_NN.part2.json` … (แต่ละไฟล์เป็น array สมบูรณ์)

## กติกาการทำงาน
- **ห้าม spawn subagent ต่อเด็ดขาด**
- อ่านได้เฉพาะ: ไฟล์ชิ้นของคุณ + ไฟล์บรีฟนี้ + Grep เป็นจุด ๆ ใน `translations/glossary.md` —
  **ห้ามอ่าน `extracted/` · `translations/master_th.json` · `translations/done/` · `HANDOFF.md` · `docs/` · ชิ้นของคนอื่น** (นี่คือการทดสอบแบบไม่เห็นต้นฉบับ)
- ห้าม print คำแปล/JSON ยาว ๆ ลงแชตหรือ console — ส่งงานเป็นไฟล์เท่านั้น
- คำตอบสุดท้าย ≤ 10 บรรทัด: จำนวนบรรทัดที่อ่าน · จำนวน finding แยกหมวด · จำนวน high/mid · **คะแนนอ่านลื่นของชิ้นนี้ 1-5**
  (5 = อ่านเหมือนบทไทยแท้ · 1 = สะดุดแทบทุกบรรทัด) พร้อมเหตุผลหนึ่งประโยค · แพตเทิร์นที่เจอซ้ำบ่อยสุด 3 อย่าง · ชื่อไฟล์ที่เขียน
