## ตรวจตามหัวข้อพิเศษของ lead (ผลทีละข้อ)

1. **มาฟุยุใช้ "ฉัน"** — ตรวจครบทุกบรรทัดที่เป็นของเธอ (id 1487/1495 ยืนยันด้วยการไล่ id ในตาราง
   `speech_list_judge_main_c13` แถว 205-238 และ 295-296 ของ `sound_auth.bin.json`) ไม่มีบรรทัดไหนพูดในฐานะ
   อัยการทางการ — ทั้งสองฉาก (บรรยายปูมหลังครอบครัวโมริตะ + สารภาพผิดที่บอกโมริตะเรื่องยากามิ) เป็นการ
   คุยกันเองในกลุ่มเพื่อน ไม่มีบรรทัดที่แถลงจุดยืนสำนักงานอัยการหรือคุยกับอิซุมิดะแบบทางการ (ฉากมิโจเระ
   เธอไม่อยู่ในเหตุการณ์แล้ว) → ไม่พบ "ดิฉัน" ในไฟล์เลย (grep ยืนยัน) ไม่ต้องแก้
2. **id 1494/1499 = โฮชิโนะ** — ยืนยันซ้ำด้วยการไล่ id ใน `sound_auth.bin.json` โดยตรง:
   id 1494 = "Yagami-san! I didn't realize you'd be stopping by..." + "Okay, okay, okay!.../Hoooold on!..."
   + "Or maybe it is!?/Maybe it isn't!" (แถว 283/285/286) · id 1499 = "Um, about what you saw just now..."
   + "Please don't tell Genda-sensei..." (แถว 306/307) — ทั้งสอง id แปลด้วย "ผม" + ครับ ตรงกับเพศชายของ
   โฮชิโนะ ส่วนซาโอริแยก id ชัดเจน (1496 = "Well, Hoshino-kun was just—" / "Maybe you'll get further next
   time." ซึ่งพูดถึงโฮชิโนะในบุคคลที่สาม เป็นหลักฐานว่าไม่ใช่คนเดียวกัน) → ถูกต้องแล้ว ไม่ต้องแก้
3. **อายาเบะ T1 ทั้งฉาก** — grep "กู/มึง/แก" ทั้งไฟล์ พบแต่คำว่า "แก้แค้น"/"แก้ต่าง" (ไม่ใช่สรรพนาม)
   ไม่มี T3 หลุดเลย ความห้าวถ่ายผ่านสำนวน ("ไอ้สัตว์ตัวนั้น", "ไอ้ยาเวรนี่") ไม่ใช่สรรพนาม — ผ่าน
4. **ยากามิระเบิดอารมณ์ยังเป็น "ผม"** — ตรวจบรรทัดโกรธทั้งหมด (id 1489: "How can you begin to think
   that's right!?", "Morita may have his ideals, but so do I." ฯลฯ) คำแทนตัวยังเป็น "ผม" ทุกจุด
   อารมณ์มาจากคำ ("ทั้งหมดนี้เพื่อไอ้ยาเวรตัวเดียว", "คิดได้ยังไงว่ามันถูกต้อง!?") ไม่ใช่การลดทะเบียน — ผ่าน
5. **อิซุมิดะ** — เรียกยากามิด้วยชื่อเปล่าตรงตาม EN ("ยากามิ? มาทำอะไรที่นี่!?") ไม่มี honorific หลุดเข้ามา
   โทน "อัยการที่กำลังชั่งใจ" คงอยู่ (เช่น "...Maybe you're not so bad." → "...อาจจะไม่ได้แย่ขนาดนั้นนี่นา") — ผ่าน

   ทะเบียน/คำล็อกตรงกันทุกคู่ที่สุ่มตรวจ — ผ่าน
