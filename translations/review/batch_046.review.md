จุดนี้จึงไม่กระทบไฟล์จริง

## 2) อิซุมิดะ — ⚠ ไม่มีบทพูดของอิซุมิดะเองอยู่ใน batch_046 เลย (ประเด็นที่ lead ถามพลาดเป้า — ไปเจอบั๊กจริงแทน)

ไล่ทั้ง batch แล้วอิซุมิดะปรากฏแค่ในบทพูด**อ้างถึง**เขา 2 จุด ("Hello, Izumida-san? This is Fujii." /
"Izumida-san says he'll send some officers over for me.") — ทั้งสองพูดโดย **มาฟุยุ** ไม่ใช่อิซุมิดะพูดเอง
(ยืนยัน id 883 = มาฟุยุ ดูข้อ 3) เช็ค `docs/story_context_judge.part1.md` เพิ่มด้วยพบว่าอิซุมิดะคือ **อัยการ**
("ยากามิต้องไปเผชิญหน้ากับอัยการ Izumida ที่สำนักงานอัยการ" + คำพูด "Objection!"/"Your Honor!" ใน
`speech_speaker_map.json`) ไม่ใช่ตำรวจตามที่ brief เขียน — เพศชายยืนยันแล้ว (`voicer_gender.json`) แต่ไม่กระทบ
batch นี้เพราะไม่มีบทพูดของเขาให้ตรวจ

**สิ่งที่เจอแทน**: บทพูด "-kun" ที่ดูเหมือน brief จะเข้าใจว่าเป็นอิซุมิดะ แท้จริงเป็นของ **มาฟุยุ** (เธอเรียก
ยากามิว่า "ยากามิคุง" ในฉากคุยกันหลังช่วยเธอรอด) — และตรงนี้เจอบั๊กจริง: นักแปลใส่สรรพนามแทนตัว "ผม"
(เพศชาย) ให้บทพูดของมาฟุยุ (เพศหญิง ยืนยันจาก `gender_evidence_judge.md`: "She also happens to be
childhood friends... dated Yagami") **4 จุด** — แก้เป็น "ฉัน" ให้ตรงกับที่นักแปลใช้เองในบทพูดข้างเคียงของ
มาฟุยุอยู่แล้ว ("ไม่ต้องห่วงฉันหรอกนะ", "ฉันจะอยู่ให้ห่างจากคามุโรโจ"):

| EN | ก่อนแก้ | หลังแก้ |
|---|---|---|
| "In fact, maybe you should come with me,\nYagami-kun. Lay low for a while." | ...ไปกับ**ผม**ด้วยนะ | ...ไปกับ**ฉัน**ด้วยนะ |
| "Honestly, Yagami-kun, maybe it'd be better\nif you came with me." | ...ถ้านายไปกับ**ผม** | ...ถ้านายไปกับ**ฉัน** |
| "You know, it's been three years\nsince I've seen you this worked up." | ...ที่**ผม**ไม่เห็นนาย... | ...ที่**ฉัน**ไม่เห็นนาย... |
| "...I've seen you this worked up, Yagami-kun." (alt) | ...ที่**ผม**\nไม่เห็นนาย... | ...ที่**ฉัน**\nไม่เห็นนาย... |

ยืนยัน id ผู้พูด = 883 ตลอด (จาก `sound_auth.bin.json`) เดียวกับ "Don't worry about me...", "That would mean...
The Shinpei Okubo case?", "It's kinda refreshing, actually.", "You just look so... alive." (มาฟุยุพูดชม
ยากามิที่กลับมามีชีวิตชีวา) ส่วนคำตอบ "Maybe I am. See you later." เป็นยากามิ (id 885 — ยืนยันจากบริบท
รับคำชม) แปลไว้ถูกอยู่แล้ว (ไม่มีสรรพนามให้หลุด)
