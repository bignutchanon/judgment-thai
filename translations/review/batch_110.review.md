## แก้ไปทั้งหมด 2 จุด

1. **`The Chase Begins!` — ศัพท์ระบบเกมไม่ตรงคำที่ ship แล้ว**
   เดิม: `การไล่ตามเริ่มขึ้น!` → แก้เป็น `การไล่ล่าเริ่มขึ้น!`
   เหตุผล: glossary §5 ล็อก `Chase(s) / Chasing → การไล่ล่า` และ `master_th.json` มีคำที่ ship แล้วตรงกัน 2 จุด
   (`"Chasing"` → `"การไล่ล่า"` idx 22529 · `"...chasing Yagami..."` → `"...ไล่ล่ายากามิ..."`)
   ยืนยันบริบทว่าเป็นระบบเดียวกันจริง: ตรวจ `extracted/db_en/en/ui_text.bin.json` idx 1761-1770 พบ `The Chase Begins!`
   อยู่ในบล็อกเดียวกับ `Distance Gauge` / `You're Losing Them!` / `Chase Complete!` / `Tailing Complete!` / `Tail the Target!`
   คือระบบ Chase/Tailing เดียวกันแน่นอน — นักแปลใช้คำคนละคำ (ไล่ตาม แทน ไล่ล่า) ทำให้ไม่นิ่งกับที่ ship แล้ว

2. **`Capture` — นักแปลระบุว่าเดา แปลผิดความหมาย**
   เดิม: `ถ่ายภาพ` (take a photo) → แก้เป็น `จับกุม`
   เหตุผล: ตรวจ `extracted/db_en/en/ui_text.bin.json` idx 1765 พบว่า `Capture` อยู่ในบล็อกเดียวกับ `Distance Gauge`
   (idx 1763-1764) ตามด้วย `You're Losing Them!` / `Chase Complete!` / `The Chase Begins!` / `Tailing Complete!` /
   `Tail the Target!` (idx 1766-1770) ทั้งหมด — คือคำในระบบ **Chase (ไล่ตามจับตัว)** ไม่ใช่ระบบถ่ายภาพ (ระบบถ่ายภาพ
   ที่แท้จริงคือ `Check the photo` ซึ่งอยู่คนละบล็อกไกลกัน idx 974) · เช็กเพิ่มด้วย web search (walkthrough Judgment
   chase minigame) ยืนยันว่ากลไกคือ "close the distance and **capture** the target" = วิ่งไล่จนเข้าใกล้แล้วจับตัวได้
   จึงแปลว่า "ถ่ายภาพ" ผิดความหมายไปคนละเรื่อง แก้เป็น "จับกุม" ให้ตรงกับกลไกจริงและสอดคล้องโทนงานสืบสวน

## จุดที่นักแปลบอกว่าเดา — ตรวจแล้วไม่มีปัญหา (ไม่แก้)

- **`"Move Pick (Left/Right)　/"` → "เลื่อนเลือก (ซ้าย/ขวา)　/"**: ตรวจ context idx 880-889 พบอยู่ในเมนู
  Settings/Controls (`Settings · Back · Cancel · Confirm · Reset · View Rules · Change Controls`) คู่กับ
  `Move Pick (Up/Down)` — เป็นคำอธิบายปุ่มเลื่อนเคอร์เซอร์เลือกในมินิเกมกระดาน แปลถูกความหมายแล้ว ช่องว่างเต็ม
  ความกว้าง `　` ท้ายคำตรงกับต้นฉบับ
- **`"Think it Over..."` → "คิดทบทวน..."**: ตรวจ context idx 707-713 พบอยู่ในบล็อกระบบยื่นหลักฐาน
  (`Threat · Show this evidence? · Evidence List · Reveal the Evidence! · Think it Over... · Zoom Out`) —
  แปลตรงความหมายตรงตัวถูกต้องแล้ว ใช้ได้กับสถานะ "รอ/กำลังพิจารณา" ระหว่างเลือกหลักฐาน
- **`"Complete Total"` / `"Completion"` → "จำนวนที่ทำครบ" / "ความคืบหน้า"**: ตรวจ context idx 1155-1164
  พบอยู่ในเมนู City Missions (`City Missions · Shop Missions · Profile · Shops · City · Display List ·
  Complete Total · No Data · "/" · Completion`) — มี `"/"` เป็นคีย์แยกต่างหากถัดจาก `Complete Total` ยืนยันว่าใช้
  แบบเศษส่วน "Complete Total: X/Y" คำแปลทั้งสองคำเข้าบริบทได้ ไม่ผิด
- **คลัสเตอร์ `Clear Prize` / `Clear Prize Money` / `Random Slot` / `Dice Left` / `No Bonus Reward` /
  `Total Exchange Value`**: ตรวจ context idx 1827-1839 ยืนยันเป็นมินิเกมกระดานทอยลูกเต๋า (มี `Check Bonus Rewards`,
  `Not Achieved`, `List of Items Received` อยู่ในบล็อกเดียวกัน) — คำแปลทั้งชุดตรงกับกลไกเกมกระดาน+แลกรางวัล
  ไม่มีจุดไหนหลุดความหมาย
- **`"Guests"` → แขก · `"Sales"` → ยอดขาย**: ยืนยันตามที่ lead ตัดสินไว้แล้วว่าเป็นบริบทคาบาเรต์คลับจริง
  (context ครบชุด `Tonight's Shift · Hostess List · Club Status · Total Sales · Total Fans · Set Charge Sales ·
  Food/Drink Sales · Staff Salaries`) — นักแปลเขียนทับ ref_tm (ที่คง EN ตรงตัว) ถูกต้องแล้ว ไม่ต้องแก้

## ตรวจแล้วไม่พบปัญหา (งานมาตรฐาน)

- **ศัพท์โป๊กเกอร์ฝั่งเดิมพัน**: ตรวจครบทุกคีย์ตรงกับ glossary ที่ล็อกใหม่ 100% — `Call→คอล · Fold→โฟลด์ ·
  Raise→เรส · Big Blind→บิ๊กบลายด์ · Little Blind→ลิตเทิลบลายด์ · Total Bet→เดิมพันรวม · Round→ยก` — ไม่มีจุดไหน
  สลับไปใช้ "รอบ" · ยืนยันเพิ่มว่านักแปล**ไม่ได้ตกหลุมพราง ref_tm** ที่ผิดอยู่แล้ว (`"Round": "สะโพก"` — MT
  แปลผิดทั้งคำ เข้าใจว่า "round" = สะโพก/ก้น) เขียนทับด้วยคำล็อกที่ถูกต้องแทน
- **โครงสร้างไฟล์**: เทียบคีย์ worklist vs done ด้วยสคริปต์ — ตรงกันครบ 250/250 ไม่ขาดไม่เกิน
- **placeholder/tag/`\n`/ช่องว่างท้ายบรรทัด/ช่องว่างเต็มความกว้าง `　`**: ไล่เทียบทุกคีย์ด้วยสคริปต์ (leading/trailing
  space, จำนวน `\n`, จำนวน `　`, `####`) — ตรงกับต้นฉบับ 100% ไม่พบ mismatch แม้แต่จุดเดียว
- **อักษรละตินมีเครื่องหมาย/Cyrillic**: สแกนทุกคำแปลด้วยสคริปต์ — ไม่พบ
- **ความสม่ำเสมอภายใน batch**: `Lap→รอบ` ใช้นิ่งทุกจุด (`Number of Laps, 1st/2nd/3rd Lap, Final Lap`) ·
  `Tailing→การสะกดรอย` ตรงกับที่ ship แล้วใน master_th.json (`สะกดรอยตาม...` หลายสิบจุด) · หมายเหตุเล็กที่ไม่ถึงขั้น
  ต้องแก้: `"2nd Lap"→"รอบสนามที่ 2"` ใช้คำว่า "รอบสนาม" แต่ `"Second Lap"→"รอบที่สอง"` ไม่ใช้ — เช็กแล้วเป็นคีย์คนละ
  ตัวจริง (idx 5158-5190 อยู่ติดกันแต่แยก entry) คาดว่าเป็นข้อความคนละสไตล์ในหน้าจอเดียวกัน (ป้าย HUD แบบย่อ vs
  ข้อความแบนเนอร์เต็มรูป) จึงไม่ฟันธงว่าผิด — แจ้งไว้เผื่อ lead อยากเช็กจอจริง
- **ความยาว**: ไล่เทียบสัดส่วนความยาว EN/TH ทั้ง 250 คีย์ — คำที่ยาวเกิน 1.8 เท่าล้วนเป็นคำ EN สั้นมาก
  (`Done, Sort, Funded!, Rarity　, Done!, % Held`) ที่ภาษาไทยไม่มีรูปย่อเทียบเท่า ความยาวสัมบูรณ์ยังสั้น
  (4-9 ตัวอักษร) ไม่เสี่ยงล้นกล่อง ไม่ถือว่าผิด
- **คำราชาศัพท์**: ไม่พบการใช้ในทั้ง batch (เป็นป้าย UI ล้วน ไม่มีบทพูด)
