# QC — batch_050 (บทที่ 7: ซื้อชุดที่เลอมาร์เช่ → สมัครฮอสเตสสวมรอยที่ควีนรูจ → เก็นดะเรียกยากามิ + เรื่องเล่าอดีตของมาฟุยุ)

สถานะ: **ผ่าน `merge_qc.py --dry-run --only 050` → ตก 0** (250/250)

## สรุปที่แก้ (4 จุด ใน 2 หมวด)

### 1. สรรพนามซาโอริหลุดจากกฎ "ฉันในฉากส่วนตัว/ดิฉันในบริบททางการ" (3 จุด)

ไล่ speaker-slot id ในตาราง `speech_list_judge_main_c07` ของ `extracted/db_en/en/sound_auth.bin.json`
(index 126 ในไฟล์ ตรงกับวิธีที่ผู้ตรวจ batch_047 ใช้) พบว่าทั้งช่วง idx 42-131 (ฉากลองชุด/เล่าเรื่องมาฟุยุ)
เป็นบทสนทนา **สองคนล้วน** ระหว่างซาโอริ (speaker id คงที่ตลอดฉาก) กับยากามิเท่านั้น ไม่มีคนที่สามหรือ
บริบททางการแทรกเลย — ยืนยันว่านี่คือ "ฉากส่วนตัวกับยากามิ" ทั้งฉากตามนิยามในบรีฟ

นักแปลใช้ "ฉัน" ถูกต้องเกือบทั้งฉาก (idx 42,54-61,64-69,108,109,121 ฯลฯ) แต่หลุดเป็น **"ดิฉัน"** 3 จุด
ในช่วงเล่าเรื่องแนะนำยากามิให้รู้จักมาฟุยุที่บาร์เทนเดอร์ (ยังเป็นฉากส่วนตัวเดียวกัน ไม่ใช่บริบททางการ):

- `"Yagami-san... Do you remember when I first introduced you?..."` — เดิม "ตอนที่**ดิฉัน**แนะนำ..."
  (คู่ paraphrase `"Do you remember when I first introduced you two..."` ข้างบนใช้ "ฉัน" อยู่แล้ว
  → เดิมสองสำนวนไม่ตรงกัน)
- `"So, I wanted Mafuyu to meet someone better..."` — เดิม "**ดิฉัน**เลยอยากให้มาฟุยุ..."
- `"So I figured... maybe Mafuyu could meet someone better..."` — เดิม "**ดิฉัน**ก็เลยคิดว่า..."
  (สองจุดหลังเป็นคู่ paraphrase กันเอง ทั้งคู่ใช้ "ดิฉัน" ตรงกัน แต่ผิดกับโทนฉากรอบข้าง)

แก้ทั้ง 3 จุดเป็น "ฉัน"

**ผลข้างเคียงจากการแก้**: `merge_qc.py` → `check_pronoun_pairs.py` classify "ฉัน" เป็น T2 ล้วน ๆ
(ไม่รู้จักกรณี "ฉัน (หญิง กลาง ๆ)" ที่ยังอยู่ T1 ตาม `PRONOUN_MATRIX.md` §0) พอ "ฉัน" มาอยู่ประโยคเดียวกับ
"คุณ" (เรียกยากามิ) เลยติด error "ผสมข้ามระดับ" ปลอม 3 จุด — แก้โดย **ตัดคำเรียก "คุณ" ทิ้งแบบ pro-drop**
(ธรรมชาติของไทยละกรรมได้เมื่อชัดเจนจากบริบท ความหมายไม่เปลี่ยน) แทนที่จะย้อนกลับไปใช้ "ดิฉัน":
- "ตอนที่ฉันแนะนำให้~~คุณ~~รู้จักกันครั้งแรก..."
- "เลยชวน~~คุณ~~มาไงล่ะ" / "เลยชวน~~คุณ~~มา"

รันผ่าน `--dry-run` แล้วยืนยันว่าไม่มีจุดไหนอื่นในทั้งไฟล์ที่มี "ฉัน" กับ "คุณ" อยู่ประโยคเดียวกัน
(เช็คด้วยสคริปต์แยกก่อนแก้ — เจอแค่ 3 จุดนี้)

### 2. คู่ paraphrase ใช้คำเรียกคนละคำ (1 จุด — เจอระหว่างไล่ speaker id ช่วงต้นไฟล์)

`row531` ของตาราง c07 (speaker id เดียวกัน, ตัวแปรสั้น/ยาวของบทเดียวกัน):
- `"And... why do you know that, exactly?"` → "ทำไม**คุณ**ถึงรู้เรื่องนี้ล่ะ" (ถูก)
- `"...Hoshino-kun, why do <font_kind=yakuza_italic>you</font_kind> know that, exactly?"`
  → เดิม "ทำไม<italic>**นาย**</italic>ถึงรู้เรื่องนี้ล่ะ" (ไม่ตรงกับคู่ข้างบน)

ผู้พูดคนเดียวกัน (id 965) ใช้ "คุณ" เรียกคู่สนทนาซ้ำอีกทีที่ idx 24/25 ("รู้สึกว่าเรื่องนี้ควรเป็น**คุณ**...")
ทั้งสองจุดในฉากเดียวกัน ยืนยันว่าโทนตัวละครนี้คือ "คุณ" ตลอด — แก้ "นาย" → "คุณ" ให้ตรงกับคู่ paraphrase
และตรงกับที่ตัวเองใช้ที่อื่นในฉากเดียวกัน

## จุดที่ยังไม่แน่ใจ อยากให้ lead ตัดสิน

1. **ช่องว่างของ `check_pronoun_pairs.py`**: สคริปต์ไม่รู้จัก "ฉัน (หญิง กลาง ๆ)" เป็น T1 ตาม
   `PRONOUN_MATRIX.md` §0 บรรทัดที่ 2 (`ผม/ดิฉัน (หญิงทางการ)/ฉัน (หญิงกลาง ๆ) ↔ คุณ`) — เจอทุกครั้งที่ตัวละครหญิง
   ใช้ "ฉัน" คู่กับ "คุณ" ในประโยคเดียว (เคสซาโอริ batch นี้) ตัวตรวจจะฟ้อง "ผสมข้ามระดับ" เป็น false positive
   ผู้ตรวจแก้เลี่ยงด้วยการตัด "คุณ" แบบ pro-drop ในทั้ง 3 จุด (ความหมายไม่เปลี่ยน) แต่ถ้า batch ถัดไปเจอ
   ประโยคที่ตัด "คุณ" ไม่ได้โดยไม่เสียความหมาย (เช่นต้องระบุตัวรับชัดเจน) จะแก้แบบนี้ไม่ได้ — เสนอให้ lead
   พิจารณาเพิ่ม `SELF["T1"]` ให้รวม "ฉัน" แบบมีเงื่อนไข (ผูกกับ `gender: female` ของผู้พูด) หรือทำ
   `translations/pronoun_exceptions.json` ให้รองรับเคสนี้เป็นกติกาถาวร — ผู้ตรวจไม่ได้แก้ไฟล์นั้นเองเพราะอยู่
   นอกขอบเขตที่บรีฟอนุญาต (ไม่ใช่ไฟล์ batch ตัวเอง)
2. ไม่มีจุดอื่นที่ต้องให้ lead ตัดสินเพิ่มเติม — เนื้อหาที่เหลือของ batch (ความหมาย/โทน/ความยาว/glossary)
   ตรวจแล้วไม่พบปัญหา
