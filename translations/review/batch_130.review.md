- `advsida33_030_select_02` (idx 977): `"She's my stalker."` / `"She's my ex-girlfriend."` / `"She's got the wrong guy."`

ตามชื่อ subtable `advsida33_030` ตรงกับไซด์เคส **A33 "Worst Birthday Ever"** (`docs/side_content_context_judge.md` §1.6): Tatsuro ขอให้ยากามิเอ็นเตอร์เทนภรรยาที่เมาจนคิดว่ายากามิเป็นสามีตัวเอง — ฉากนี้ภรรยาที่เมาถามยากามิ (สวมบทบาทเป็นสามี) เกี่ยวกับคนในรูป/ความสัมพันธ์ เพื่อทดสอบว่าเป็นสามีจริงไหม select_01 = คำถามเกี่ยวกับผู้ชายในรูป, select_02 = คำถามเกี่ยวกับผู้หญิงในรูป (คนละชุดคำถาม คนละรูป ไม่ใช่คำถามเดียวกัน)

**สรุป: คำแปลปัจจุบันจัดประเภทถูกแล้วทั้ง 6 จุด ไม่ต้องแก้** — ทั้งหมดเป็นคำตอบที่ยากามิพูด (สวมบทบาทสามี) จึงต้องใช้สรรพนาม "ผม" ตามกฎ "ยากามิ = T1 เสมอ" แม้อยู่ในบทสวมบทบาท:
- "My father." → "พ่อ**ผม**เอง" ✓ · "My younger brother." → "น้องชาย**ผม**เอง" ✓
- "She's my stalker." → "เธอเป็นสตอล์กเกอร์ของ**ผม**" ✓ · "She's my ex-girlfriend." → "เธอเป็นแฟนเก่า**ผม**" ✓
- "The captain." → "กัปตันน่ะ" และ "She's got the wrong guy." → "เธอจำคนผิดน่ะ" — ไม่มีสรรพนามในประโยคต้นฉบับ (fragment สั้น) แปลแบบไม่ใส่สรรพนามเพิ่มก็ถูกต้อง ไม่ขัดกับสองคู่ข้างบน

⚠ หมายเหตุ: `"captain"` ในคีย์นี้เป็นคำตอบทั่วไปในเกมทายภาพ **ไม่เกี่ยวกับ** "Captain" ที่กำกวมของฮามุระ/ไคโตะ (glossary §10) — บริบทคนละฉาก ไม่ชนกฎ
