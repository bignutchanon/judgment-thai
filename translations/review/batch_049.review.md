## 2. สแกนยากามิใช้ "แก"/T3

grep คำว่า "แก" ทั้งไฟล์ (250 คู่) — เจอ 1 จุดเป็น false positive (คำว่า "สแกน" มี "แก" อยู่ในคำ ไม่ใช่สรรพนาม)
**ไม่มียากามิหลุด T3 แม้แต่จุดเดียว** — ยากามิใช้ "ผม" ล้วนตลอด batch รวมฉากยากูซ่าเกียวโตที่ตัวเองก็อยู่ในที่เกิดเหตุ
(เช่น "ผมจะไม่โทรแจ้งตำรวจ", "ผมโทรเองก็ได้") และเรียกยากูซ่ากลับด้วย "นาย" ตามกฎ ไม่ใช่ "แก"

ตามความเป็นทางการของฉาก) — ตรวจทุกบรรทัดของ id 961 ใน batch นี้ **ไม่เจอ "ผม" หลุดแม้แต่จุดเดียว**
(บั๊กที่ batch_047 เคยเจอ) เธอใช้ "ฉัน" ตลอด batch นี้ (ฉากมินิเกม/ตอนกินโมจิ/ถกเรื่องฮอสเตส — บริบทเป็นเรื่องส่วนตัว/
