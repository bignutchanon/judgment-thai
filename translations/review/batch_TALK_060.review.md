## รายการที่ตรวจเพิ่มเติม (นอกโจทย์ที่นักแปลรายงาน) — ผ่านทั้งหมด

- **ยากามิ T1 "ผม" เสมอ** — ตรวจครบ 250 บรรทัดด้วย speaker map ยืนยันแล้ว ไม่พบสลับเป็น "ฉัน"/"แก"/"กู"/"มึง"
- **ทะเบียนนานามิ/ยุกโกะ** — T1 "ฉัน"/"ดิฉัน"+ค่ะ ตาม `characters_side.json` สม่ำเสมอทั้ง batch ไม่พบสลับ
  ทะเบียนกลางประโยค
- **แท็ก `<font_kind=yakuza_italic>`** — เทียบจำนวน/ลำดับแท็กเปิด-ปิดทุกคู่ EN↔TH ด้วยสคริปต์ (regex `<[^>]+>`)
  ตรงกันครบ 250/250 จุด ไม่มีแท็กหาย/เกิน/สลับตำแหน่ง
- **จำนวน `\n`** — ตรวจอัตโนมัติทุกคู่ ตรงกันครบ 250/250
- **ช่องว่างไทย-ละติน** — สแกน regex หาอักษรไทยชนอักษรละตินโดยไม่มีช่องว่างคั่น (นอกขอบเขตแท็ก) พบ 0 จุด
- **คำราชาศัพท์** — ไม่พบ "ทรง-/พระองค์" หลุดในไฟล์นี้
- **เวลา AM/PM** — batch นี้ไม่มีการอ้างเวลานาฬิกา
- **ความยาว** — ไม่พบบทพูดที่ยาวเกิน EN จนน่าห่วงเรื่องล้นกล่องข้อความ
