## จุดที่ lead สั่งตรวจเป็นพิเศษ — ผลตรวจ

1. **ฮาชิโมโตะ = หญิง** — ไล่ทุกบรรทัดของเธอ (id1219/1220/1227/1229) แล้ว พบ 2 จุดที่ผิดเพราะ **สลับตัวผู้พูดกับยากามิ**
   (ไม่ใช่แค่ "เลี่ยงสรรพนาม" ตามที่สั่งให้ระวัง) — แก้แล้วทั้งคู่ (ดูหัวข้อบนสุด "Dr. Shono slipped away" และ "Gotta run!"
   ซึ่งจริง ๆ เป็นของยากามิ). บรรทัดอื่นของเธอ (greeting, self-intro, อธิบายตารางตรวจรอบ, คำอำลาจริง "And with that,
   I should be going...") ใช้ "ฉัน/ค่ะ" ครบถูกต้องอยู่แล้ว
2. **"There's a good boy." / "Good boy."** — id คือ **1252** แยกจาก id ที่คุมบทซักโชโนะหลัก (**id1253 = ยากามิ**
   ยืนยันชัดจากน้ำเสียงเชิงกฎหมาย "You just made a big mistake, Shono-san." + ต่อเนื่องจาก "It's about time I got answers"
   ของยากามิก่อนหน้า) — id1252 ไม่ปรากฏซ้ำที่อื่นในฉากนี้ให้ยืนยันได้ตรง ๆ แต่ pattern สอดคล้องกับ **ไคโตะ** มากกว่า
   (เทียบกับ id1250 "Open up! Hey!" ที่คุมโดยคนละ id จาก 1253 เช่นกัน น่าจะเป็นไคโตะทุบประตูก่อนเข้าไป) — **ความมั่นใจปานกลาง
   เท่านั้น ไม่ใช่ยืนยันเด็ดขาด** เพราะไม่มีบรรทัดที่ระบุตัวตรง ๆ แบบ "My name is..." ให้ยึด
   → คำแปลปัจจุบัน "เด็กดี"/"เด็กดีมาก" **ไม่มีปัญหาแม้ยังไม่ยืนยันตัวผู้พูด** เพราะเป็นคำชมประชดที่ไม่ใช้สรรพนามแทนตัว/เรียกคู่สนทนา
   เลย (ไม่ผูกเพศ ไม่ผูกระดับ T) จึงถูกต้องไม่ว่าจะเป็นยากามิหรือไคโตะพูด — **ไม่ได้แก้ไข** เพราะไม่มีจุดให้แก้จริง แต่แจ้ง lead
   ว่าแท็ก `speaker_exact: sugiura` ใน `speech_speaker_map.json`/`gender_evidence` ผิดแน่นอน (ซุกิอุระไม่อยู่ในฉากนี้) ควรแก้เป็น
   ไคโตะ (ความมั่นใจปานกลาง) หรืออย่างน้อยลบแท็กผิดออก
3. **"You again." / "...You."** — ยืนยันด้วย id ชัดเจน: **id1226 = ยากามิ** (ไม่ใช่อิจิโนเสะ) — ยืนยันจากบทเดียวกันที่ id1226
   พูด "Aren't you the Vice Minister of Health?" และ id1224 (อิจิโนเสะ) ตอบ "My name is Ichinose./It's Ichinose."
   สลับกันเป็นคู่สนทนาเดียวตลอดฉาก → คำแปลเดิม "มาอีกแล้วเหรอเนี่ย" / "...คุณนี่เอง" **เป็น T1 ไม่มี "แก" อยู่แล้ว ถูกต้องตามกฎ
   ไม่ต้องแก้** (นักแปลเลี่ยงสรรพนามไว้เผื่อผู้พูดเป็นอิจิโนเสะ แต่เมื่อยืนยันเป็นยากามิแล้วโทนที่ใช้ก็ยังอยู่ใน T1 พอดี)
4. **มาชิโกะ (ชาย, T1 "ผม")** — ไล่ทุกบรรทัดของเขา (id1236/1239) พบว่า EN **ไม่หยาบถึงระดับ fuck/asshole/punk เลย**

   — มาชิโกะเองใช้โทนบริการ/ทางการแม้ตอนท้าทายชก ("I'm sorry, but I'll have to escort you...", "Now fight me!"/
   "Let's go, detective!" ไม่มีคำสบถ) → คงทะเบียน T1 "ผม" ทั้งฉากถูกต้องแล้ว **ไม่ต้องขยับเป็น T3**
5. **ยากามิห้าม "แก/กู/มึง"** — ไล่ทั้ง batch ไม่พบจุดที่ยากามิใช้คำเหล่านี้เลย (ผ่าน)
