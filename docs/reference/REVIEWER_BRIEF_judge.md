# บรีฟผู้ตรวจ (QC) — Judgment ม็อดแปลไทย (JETH)

ผู้ตรวจคือคนที่สองของ "คู่" — นักแปลส่งงานแล้วคุณตรวจก่อนงานจะถูก merge เข้า `master_th.json`
เครื่องตรวจอัตโนมัติ (`merge_qc.py`) จับได้แค่ปัญหาเชิงกล (tag/บรรทัด/สรรพนามผสมระดับ/ฟอนต์)
**งานของคุณคือคุณภาพของภาษาและความถูกต้องของบริบท ซึ่งเครื่องจับไม่ได้**

## อ่านก่อนตรวจ

`docs/reference/TRANSLATOR_BRIEF_judge.md` (กฎเดียวกับที่นักแปลต้องทำตาม — รวมงบ token ≤120k)
· `translations/glossary.md` · `translations/PRONOUN_MATRIX.md` §0/§0.1
· `translations/characters_main.json` / `characters_side.json`

## ตรวจอะไรบ้าง (เรียงตามความสำคัญ)

1. **แปลผิดความหมาย / ตรงข้ามกับต้นฉบับ** — ร้ายแรงที่สุด ต้องเทียบ EN ทีละบรรทัด
2. **สรรพนามผิดคู่หรือผิดคน** — ระดับ (T1/T2/T3) ต้องตรงกับความสัมพันธ์จริงในฉากนั้น
   · ยากามิต้องเป็น "ผม" เสมอ · เพศผู้พูดที่ยังพิสูจน์ไม่ได้ต้องเลี่ยงสรรพนาม/ครับ-ค่ะ
3. **คำล็อกไม่ตรง glossary** (ชื่อคน/สถานที่/องค์กร/ศัพท์กฎหมาย เช่น alibi = พยานที่อยู่)
4. **โทนผิดบุคลิก** — ยากูซ่าพูดสุภาพเหมือนพนักงานออฟฟิศ, ตัวละครทางการพูดห้วนเกิน ฯลฯ
5. **ภาษาไทยไม่เป็นธรรมชาติ** — แปลตรงตัวจนอ่านสะดุด, เรียงประโยคแบบอังกฤษ, คำซ้ำเยิ่นเย้อ
6. **ความยาว** — บทพูดที่ยาวกว่า EN มากจะล้นกล่องข้อความ ให้เกลาให้กระชับ
7. **คำราชาศัพท์หลุด** — ห้ามใช้ "ทรงพระเจริญ/ทรง-/พระองค์" กับตัวละครในเกมเด็ดขาด (อ่อนไหวในไทย)
8. **ความสม่ำเสมอภายใน batch** — คำเดียวกันต้องแปลเหมือนกันทั้ง batch

## วิธีทำงาน

1. อ่าน `translations/worklist/batch_NNN.json` (ต้นฉบับ EN + `ref_tm`) และ
   `translations/done/batch_NNN.done.json` (คำแปลที่ส่งมา)
2. ตรวจทีละคู่ · ที่ต้องแก้ให้ **แก้ในไฟล์ `.done.json` ได้เลย** (คุณคือคนสุดท้ายก่อน merge)
   — แก้ด้วยสคริปต์ Python (utf-8, `ensure_ascii=False`) เขียนครั้งเดียวจบ
3. รัน `python scripts/merge_qc.py --dry-run --only NNN` ต้องได้ **ตก 0**
4. เขียนบันทึกการตรวจไว้ที่ `translations/review/batch_NNN.review.md`:
   จำนวนที่แก้ · ประเภทข้อผิดที่เจอ (แยกหมวดตามข้อ 1-7) · คำที่ควรเพิ่มเข้า glossary ·
   จุดที่ยังไม่แน่ใจและอยากให้ lead ตัดสิน

## ขอบเขต

- แก้ได้เฉพาะ `translations/done/batch_NNN.done.json` + `translations/review/batch_NNN.review.md` ของ batch ตัวเอง
- **ห้ามแตะ** `master_th.json` · `slotmap.json` · glossary · ไฟล์ของ batch อื่น
- ห้ามเปิดเกม · ห้าม spawn subagent · งบ token ≤120k
- ห้ามแก้คำแปลที่ "ดีอยู่แล้วแต่ไม่ใช่สไตล์ตัวเอง" — แก้เฉพาะที่ผิดจริงตามข้อ 1-7
  (แก้พร่ำเพรื่อทำให้เสียงในเกมไม่นิ่งพอ ๆ กับแปลผิด)
