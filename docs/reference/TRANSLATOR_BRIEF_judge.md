## กฎเหล็กของงานแปล

1. **สรรพนามมาเป็นคู่** (PRONOUN_MATRIX §0) — เลือกระดับก่อน แล้วใช้ทั้งสองฝั่งจากระดับเดียวกัน
   - **T1 สุภาพ**: ผม / ดิฉัน ↔ **คุณ** (ครับ/ค่ะ) — ทางการ ลูกความ ตำรวจ อัยการ คนแปลกหน้า
   - **T2 กันเอง**: ฉัน ↔ **แก** (ว่ะ/นะ/เหรอ) — เพื่อนสนิท คนคุ้นเคย
   - **T3 หยาบ**: กู ↔ **มึง** (โว้ย/เว้ย) — อันธพาล/ยากูซ่าข่มขู่ เฉพาะเมื่อ EN หยาบชัด
   - ห้ามผสมข้ามระดับในบรรทัดเดียว ("ผม…มึง" = ตก QC ทันที)
   - **ยากามิ (ตัวเอก) = T1 "ผม" เสมอ** ห้าม T3 · กับคนสนิทเรียกชื่อแทน "คุณ" ได้
1.5 **ยากามิห้ามใช้ "แก" เด็ดขาด** — แม้ตอนขู่ บลัฟ หรือโมโห · คู่ T1 ของเขาคือ ผม ↔ **คุณ**
   (กับคนที่ไม่ควรใช้ "คุณ" ให้ใช้ **"นาย"** หรือเรียกชื่อ) · ผู้ตรวจเจอพลาดข้อนี้ซ้ำทุกสปรินต์

2. **เพศไม่ชัด = ห้ามเดา** — ถ้าไม่รู้ว่าผู้พูดชาย/หญิง (ดูรายชื่อ ⏳ ใน `gender_evidence_judge.md`)
   ให้เลี่ยงสรรพนามและคำลงท้ายบอกเพศ เขียนกลาง ๆ แทน
3. **tag/placeholder ต้องครบเป๊ะ**: `<symbol=...>` `<color=...>` `${name}` `%s` `%d` `~xxx~`
   ห้ามแปล ห้ามสลับลำดับถ้าไม่จำเป็น ห้ามเพิ่ม/ลด
4. **จำนวนขึ้นบรรทัด `\n` ต้องเท่าต้นฉบับ** — กล่องข้อความในเกมตัดบรรทัดตายตัว
5. **ห้ามใช้อักษรละตินมีเครื่องหมาย** (À Á Ò Ó ā ō œ ฯลฯ) — ฟอนต์เกมเอาช่องพวกนี้ไปวาดกลิฟไทยแล้ว
   จะกลายเป็นตัวไทยมั่วบนจอ · ต้องการเขียนชื่อฝรั่งให้ใช้ ASCII ล้วน (`Cafe` ไม่ใช่ `Café`)
   (`é à ç ü ñ ° × ÷` ปลอดภัยเพราะถูกสงวนไว้ แต่เลี่ยงได้ก็เลี่ยง)
6. **คงภาษาอังกฤษ** สำหรับ: license/EULA/credits, ชื่อเครื่องหมายการค้า, enum/ค่าระบบที่ไม่ใช่ข้อความแสดงผล
   — วิธีคง: ใส่ค่าเดิม (EN) เป็นคำแปล **ห้ามเว้นว่าง**
7. **ความยาว**: ไทยยาวเกิน ~1.8 เท่าของ EN จะโดนเตือน — กล่องข้อความมีจำกัด เขียนให้กระชับ
8. ชื่อเฉพาะที่ยังไม่มีในคำล็อก: ทับศัพท์ตามกฎสาย RGG (`g` กลางคำ→ก · `-ei`→เ-ย์ · `ki` ท้ายชื่อ→กิ
   · `zu`→ซึ) แล้ว **แจ้ง lead** ในรายงานจบงาน
9. ศัพท์กฎหมาย/สืบสวนต้องนิ่งทั้งเกม (`alibi` = **พยานที่อยู่** · ห้ามทับศัพท์) — ดู glossary §3

10. **ห้ามใช้คำราชาศัพท์/คำที่สงวนไว้สำหรับสถาบันพระมหากษัตริย์กับตัวละครในเกม** — เช่น "ทรงพระเจริญ" "พระองค์" "ทรง-" แม้จะเป็นมุกล้อกษัตริย์สมมติก็ตาม (เจอจริงใน batch_024: `"all hail King Kaito"` เคยแปลว่า "ทรงพระเจริญ" — แก้เป็น "ราชาไคโตะจงเจริญ!" ซึ่งใช้กับกษัตริย์ในนิยาย/เกมได้ตามปกติ) เป็นเรื่องอ่อนไหวทางวัฒนธรรมและกฎหมายในไทย ห้ามเสี่ยงเด็ดขาด

## รูปแบบไฟล์งาน

รับงานจาก `translations/worklist/batch_NNN.json`:
```json
{"priority": 1,
 "source_bins": ["caption.bin", "..."],
 "strings": {"<EN>": "", "...": ""},
 "ref_tm": {"<EN>": "<คำแปลจากภาคก่อน — เป็นร่างให้พิจารณา ไม่ใช่คำตอบ>"}}
```
- `ref_tm` = คำแปลที่ทีมนี้เคยใช้ในภาคก่อน — **ดี = ใช้ต่อ (สำคัญ: คำแปลที่เหมือนกันข้ามภาคทำให้ผู้เล่นคุ้น)
  · เพี้ยน/ไม่เข้าบริบท = เขียนใหม่** ห้าม copy โดยไม่อ่าน
- ส่งงานที่ `translations/done/batch_NNN.done.json`:
```json
{"batch": "<ไอดี batch ตามชื่อไฟล์>", "strings": {"<EN>": "<คำแปลไทย>"}}
```
⚠ **ฟิลด์ `batch` ต้องตรงกับชื่อไฟล์เป๊ะ** — คิว TALK ใช้ `"TALK_056"` ไม่ใช่ `"056"`
(ใส่ผิดแล้ว `merge_qc.py` จะไปหา `worklist/batch_056.json` ซึ่งเป็นคิวคนละชุด แล้วรายงาน
"ขาด 250" ทั้งที่แปลครบ — นักแปลสองคนติดกับดักนี้ในสปรินต์สี่)

- ต้องมี **ทุก key** ของ batch · ห้ามเว้นว่าง · UTF-8 · เขียนไฟล์ด้วยสคริปต์ Python
  (`io.open(..., "w", encoding="utf-8")` + `json.dump(..., ensure_ascii=False, indent=1)`)
  **ห้ามส่งข้อความไทยผ่าน CLI argument** (คอนโซล Windows เป็น cp1252 จะพัง)

## งบ token ต่อ batch (ธรรมเนียมทีมสืบทอดจาก K3 — บังคับ)

**ไม่เกิน ~120,000 token ต่อหนึ่ง batch** ทั้งงานแปลและงานตรวจ

- **ห้าม `Read` ไฟล์ใหญ่ทั้งไฟล์** — `talk.bin.json` (19,055 บรรทัด), `sound_auth.bin.json`,
  `items.json`, `missions.json` ให้ใช้ `Grep` เจาะเฉพาะ string ที่ต้องดูบริบทเท่านั้น
- อ่านไฟล์อ้างอิง (glossary / PRONOUN_MATRIX / characters_*) **รอบเดียว** ตอนเริ่มงาน ไม่เปิดซ้ำ
- ค้นบริบทเฉพาะ string ที่ไม่ชัดว่าใครพูดจริง ๆ — ไม่ต้องค้นทุกบรรทัด
- เขียนไฟล์ผลลัพธ์ **ครั้งเดียวจบ** ด้วยสคริปต์ Python (ห้ามเขียน/แก้ทีละ key)
- งบใกล้หมดก่อนแปลครบ → ส่งเท่าที่เสร็จ + แจ้ง lead ว่าเหลือ key ไหน **ห้ามลากยาวจนล้น context**
- ห้าม spawn subagent ต่อ (คนเดียวจบงานตัวเอง)
