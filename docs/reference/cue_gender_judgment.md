## กับดักเพิ่มของภาคนี้ (ไม่มีในเอกสารกลาง)

**คอลัมน์ `sex` บางแถวเป็นเพศของ "นักพากย์" ไม่ใช่ของตัวละคร** — ตรวจเจอสามตัวตอนกวาดรอบแรก:

| voicer | `sex` ในไฟล์ | ตัวละครจริง |
|---|---|---|
| `sumire` | 1 = ชาย | โฮสเตสหญิง (บทพูดใช้ "หนู") |
| `kjart_woman` | 1 = ชาย | พนักงานหญิงที่ KJ Art |
| `alpes_boy` | 2 = หญิง | เด็กเสิร์ฟชายร้าน Alps (ธรรมเนียมให้ผู้หญิงพากย์เด็กชาย) |

ตัวละครหลักทุกตัวที่เทียบแล้ว **ตรงกับ `translations/characters_main.json` หมด**
(ยากามิ/โฮชิโนะ/คิโดะ/ชินทานิ = ชาย · ซาโอริ/มาฟุยุ/เอมิ = หญิง)
→ กติกา: ใช้คิวเสียงเป็นหลัก แต่ถ้าขัดกับทะเบียนตัวละคร/บทในเกม **ให้ตัวละครชนะ**
แล้วใส่ชื่อ voicer ลง `SKIP_VOICERS` ใน `scripts/fix_line_gender.py` พร้อมเหตุผล

**หลักฐานสองแหล่งขัดกัน = บรรทัดใช้ร่วมกันจริง** — ถ้าคิวเสียงบอกเพศหนึ่งแต่
`talk_speaker.json` (จาก `talk.bin`) บอกอีกเพศ แปลว่าเกมเอาบรรทัดเดียวไปใช้กับผู้พูดคนละเพศ
ต้องแปลกลางเพศ (เคสจริง: `Good luck.` — คิวเป็นมาฟุยุ แต่ยากามิก็พูดประโยคเดียวกัน)

## ผลการกวาดรอบแรก (29 ส.ค. 2026)

ขัดกัน 94 บรรทัด → แก้ 87 · ข้าม 8 (ตัว `SKIP_VOICERS` ข้างบน — คำแปลเดิมถูกอยู่แล้ว)

กลุ่มที่ผิดเยอะสุดคือบทของ **ซาโอริ** (เลขาหญิงของสำนักงาน) ที่ถูกแปลด้วย "ครับ/ผม" ทั้งฉาก
และบทของ **ชินทานิ** (ทนายชาย) ที่ถูกแปลด้วย "ค่ะ" ทั้งฉาก — ทั้งสองกรณีนักแปลไม่มีทางรู้ว่าใครพูด
เพราะ `sound_auth.bin` ไม่มีคอลัมน์ชื่อผู้พูด นี่คือช่องโหว่ที่วิธีนี้ปิดให้

ตัวละครใน `timeline*.bin` กับ `talk_talker.bin` ซึ่งเป็นป้ายกำกับภายใน ไม่ใช่บทพูด)
